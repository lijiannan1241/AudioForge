FAQ

Things you may want to know first

Is everything processed locally?

Everything except speech synthesis stays on your machine: decoding, denoise, loudness analysis, spectrum, OCR and reports. The default voice service is Microsoft Edge Read Aloud; Azure, OpenAI and ElevenLabs keys can be supplied by you.

Which output formats are supported?

Seven: WAV, MP3, FLAC, M4A, AAC, OGG and Opus, with sample rate, bit depth and channels aligned in one pass. Chapter markers work in WAV / MP3 / FLAC / M4A as well as M4B.

What happens if one file fails?

The batch continues. Failed items are recorded separately and a rerun only touches those files; finished outputs are left alone.

How does it fit a game engine?

The CLI and JSON presets run in CI, and exported WAV / MP3 / FLAC / M4A are consistent enough to drop straight into Wwise or FMOD.

Does it need an account or the internet?

No account, no telemetry, no crash reporting. Only speech synthesis needs a network connection; audio files, source documents, filenames and paths are never uploaded.

What Windows version is required?

Windows 10 version 19041 or later (x64). ffmpeg is bundled, so there is nothing else to install.
