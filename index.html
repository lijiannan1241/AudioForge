核心功能

从素材到交付，一条管线

响度、格式、章节与报告不再分散在四个工具里。

01

响度归一

批量对齐到 -23 / -19 / -16 LUFS，4 倍过采样真峰值限制，实测偏差不超过 0.1 LU。

02

文档转有声书

DOCX、PDF、EPUB、SRT、MOBI 等 8 种输入；混合 PDF 逐页判断，扫描件离线 OCR。

03

318 种声音

70+ 语言先试听再决定；按句合成，支持发音词典、多角色路由与断点续传。

04

看得见的质检

每批生成 CSV / JSON / HTML 报告，附波形、STFT 频谱与六段分带能量。

05

公平 A/B

响度对齐后在同一位置切换语音，比的是音色，不是谁更响。

06

工程化就绪

JSON 预设、命令行、失败隔离与续传；可进 CI 与 Wwise / FMOD 管线。

工作方式

四步，然后重复

  1. 01

    拖入文件

    整个目录拖进窗口，或让命令行遍历输入目录。

  2. 02

    选预设

    响度目标、效果链与导出规格都已存成 JSON。

  3. 03

    跑批并报告

    每个文件独立处理，失败项隔离，报告随批产出。

  4. 04

    交付

    章节、元数据与格式一次写好，直接进引擎或播放器。

常见问题

你可能想先知道

所有处理都在本地吗？

除语音合成外全部在本机完成：音频解码、降噪、响度分析、频谱、OCR 与报告都不上传。默认语音合成走微软 Edge 朗读服务；也可自行配置 Azure、OpenAI 或 ElevenLabs 的密钥。

支持哪些输出格式？

WAV、MP3、FLAC、M4A、AAC、OGG、Opus 共 7 种；采样率、位深与声道可一次对齐。除 M4B 外，WAV / MP3 / FLAC / M4A 也能写章节标记。

一个文件失败会怎样？

不会中断整批。失败项单独记录，重跑时只补失败文件，已完成的产物保持不动。

怎么和游戏引擎衔接？

命令行与 JSON 预设可进 CI；导出的 WAV / MP3 / FLAC / M4A 规格统一，可直接进入 Wwise 或 FMOD 的导入管线。

需要联网或账号吗？

没有账号、没有遥测、没有崩溃上报。只有语音合成需要网络；音频文件、源文档、文件名与路径都不会被上传。

Windows 版本要求？

Windows 10 版本 19041 或更高（x64）。内置 ffmpeg，无需单独安装。
